# EVO — ОКНА Ш.А.Р. WordPress Block Theme

Готовая self-hosted WordPress тема для установки на Timeweb или другом обычном PHP/MySQL-хостинге.

## Что редактирует владелец

Через WordPress Site Editor/Gutenberg можно менять:
- заголовки и тексты;
- телефон и адрес;
- услуги;
- FAQ;
- кнопки и ссылки;
- меню;
- header/footer;
- цвета и типографику в рамках theme.json.

## Архитектура

- Native WordPress Block Theme.
- `theme.json` — дизайн-токены и редакторские ограничения.
- `templates/front-page.html` — главная страница.
- `parts/header.html`, `parts/footer.html` — глобальные части.
- `style.css` — локальные стили, без обязательных CDN.
- `functions.php` — подключение стилей и editor styles.

## Установка на Timeweb

1. Установить обычный WordPress на хостинге клиента.
2. Скопировать папку `okna-shar` в `/wp-content/themes/` или загрузить ZIP темы через «Внешний вид → Темы → Добавить новую».
3. Активировать тему.
4. Открыть «Внешний вид → Редактор» и проверить главную страницу.
5. В «Настройки → Чтение» выбрать статическую главную страницу, если конфигурация WordPress этого требует.
6. После переноса домена выполнить через WP-CLI: `wp search-replace 'OLD_URL' 'NEW_URL' --dry-run`, затем без `--dry-run` после проверки.

## Принцип передачи

Финальный аккаунт Timeweb, домен, база, WordPress admin и файлы темы принадлежат клиенту. EVO не требуется для дальнейшего редактирования сайта.
